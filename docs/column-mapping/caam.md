# CAAM 静态化栏目取数对照表

适用配置：`configs/caam.example.yaml`

这份表供内容管理员和运维人员录入 CAAM 数据时使用。表中的“后台栏目名称”必须与后台完全一致。

CAAM 采用“模板重新渲染”方式：静态化程序读取配置中指定的栏目和文章，再生成首页、协会概况、协会工作、统计数据、会员专区和党建专区等页面。因此 CAAM 可以按“页面区域 → 固定栏目名称”逐项建立取数对照。

## 一、内容类型

| 类型值 | 后台内容类型 | 用途 |
| --- | --- | --- |
| `1` | 图文 | 普通新闻、制度、介绍、名单等内容 |
| `2` | 视频 | 视频内容、推荐视频，也可进入允许图文/视频的普通区域 |
| `3` | 数据 | 首页统计数据和统计页图表，不生成普通文章详情 |

### 统计图表

| 页面区域 | 后台栏目名称 | 必须类型 | 页面取数方式 |
| --- | --- | --- | --- |
| 国内数据图表 | `国内数据汽车月度销量` | 3 | 读取已发布月度数据，展示最新月份及本年/上年走势 |
| 国外数据图表 | `国外数据汽车月度销量` | 3 | 读取已发布月度数据，展示最新月份及本年/上年走势 |
| 产销图表 | `产销汽车月度销量` | 3 | 读取已发布月度数据，展示最新月份及本年/上年走势 |
| 进出口图表 | `进出口汽车月度销量` | 3 | 读取已发布月度数据，展示最新月份及本年/上年走势 |

月度数据推荐每个月录入一条：

```text
类型：数据（3）
标题：汽车月度销量
摘要：2026-09
正文：245.6
```

其中摘要必须是 `YYYY-MM`，正文必须是大于或等于 0 的数字，默认单位为“万辆”。系统会自动汇总最新年份与上一年份的 1—12 月数据。

系统也兼容旧版统计 JSON，但日常录入优先使用上面的“一月一条”方式。

## 八、运维录入检查清单

- 栏目名称与本表完全一致，没有多余空格或缩写。
- 图文、视频、数据类型选择正确。
- 轮播、Logo、专题等视觉区域已经上传适合的封面。
- 外部链接使用完整的 `http://` 或 `https://` 地址。
- 统计数据摘要使用 `YYYY-MM`，正文为合法数字。
- 文章完成审核和发布，并关联到目标栏目。
- 生成对应主页面；不确定影响范围时生成全站。
