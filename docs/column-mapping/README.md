# 静态化栏目取数对照表

运维人员录入数据前，先打开对应站点的对照表。栏目名称、页面归属、内容类型或层级不符合表中要求时，即使文章已经发布，也可能不会出现在静态页面上。

- [CAAM 静态化栏目取数对照表](caam.md)
- [MIIC 静态化栏目取数对照表](miic.md)

## 使用方法

1. 确认管理后台连接的是正确数据库。
2. 按对照表创建或选择页面和栏目，不自行缩写栏目名。
3. 按要求选择内容类型、填写封面、摘要、正文或外链。
4. 完成审核和发布，确认文章已关联到目标栏目。
5. 在静态化管理中生成对应页面或全站。
6. 对照输出页面检查数据是否进入正确区域。

## 所有站点共同的发布条件

只有同时满足以下条件的数据才会参与生产静态化：

- 页面和栏目处于启用状态且未删除；
- 文章处于启用状态、审核通过且未删除；
- 文章已经发布到目标栏目；
- 文章类型受当前适配器支持；
- 栏目名称、页面名称和层级符合对应站点的对照表。

同一区域有多条数据时，通常按“置顶优先 → 发布时间倒序 → ID 倒序”取数。具体数量以各站点表格为准。
